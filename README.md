# Berusaha - Penyulingan Minyak Nilam Premium Lahendong

![Berusaha](https://img.shields.io/badge/Status-Active-brightgreen)
![GitHub Pages](https://img.shields.io/badge/Hosted%20with-GitHub%20Pages-blue)

Website resmi **Berusaha**, penyulingan minyak nilam (Patchouli Oil) premium berlokasi di Lahendong, Sulawesi Utara.

## 📋 Tentang Kami

Berusaha memproduksi **minyak nilam murni berkualitas ekspor** dengan kandungan **Patchouli Alcohol tinggi**. Kami menggabungkan metode tradisional dengan teknologi penyulingan modern untuk menghasilkan minyak nilam terbaik dari Lahendong.

### Keunggulan Kami
- ✅ Daun nilam pilihan dari perkebunan terbaik Lahendong
- ✅ Patchouli Alcohol ≥ 35% (Grade Ekspor)
- ✅ Proses penyulingan steam modern
- ✅ Pelayanan custom & private label
- ✅ Transparan dan terpercaya

## 🚀 Fitur Website

- Desain modern & responsif
- Informasi lengkap tentang perusahaan
- Proses produksi yang jelas
- Galeri foto kegiatan
- Form kontak + integrasi WhatsApp
- Optimal untuk SEO

## 🛠️ Teknologi yang Digunakan

- **HTML5** + **Tailwind CSS**
- **GitHub Pages** (Static Hosting)
- **Formspree** (Form kontak)
- Font Awesome Icons
